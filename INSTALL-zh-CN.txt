敌情预测 v3.15（简体中文汉化）

支持 Helldivers 2 Steam build 25327279 / 游戏版本 1.8.45850.0。
需要 Bingus Shared Loader v12 或更新版本 / API 1。

安装
1. 关闭 Helldivers 2，并使用一个 Mod 管理器。
2. 用 Know-Your-Constellation-v3.15.zip 替换旧包。
3. 启用本包与 Bingus Shared Loader。
4. 使用 Arsenal 默认优先级时，将加载器放在最下方（最后）；
   启用“第一个 Mod 优先”时，将加载器放在最上方（最先）。
5. 执行 Purge / Deploy（清除部署 / 部署），然后正常启动游戏。

滚动版与分行版只能启用其中一个。

显示
- 滚动版在原生面板内滚动显示敌军编组与可能遭遇的敌人。
- 分行版把同一份预测逐行静态显示，长句按字符换行。
- 重型敌人单独列出一节。
- 预测描述编组特征与符合条件的目标，不保证敌人实际生成。
- 仅安装者可见，不改变敌人生成、难度或网络通信。

语言与字体
- 请将游戏文本语言设为简体中文。本汉化沿用游戏当前语言的原生字体资源，
  字体、材质与图集都取自当前 locale，语言设置不符会导致中文无法显示。
- 字库缺字：本构建的正文 face（哈希 fbb35bee675f2295）没有「汁」（U+6C41）的字形，
  引擎会改画缺字标记（游戏里显示为问号）。因此 Bile 一律译作「吐酸」，与重型敌人
  「吐酸泰坦／阴霾吐酸泰坦」用词一致，写入文本的字形均已确认可显示。
- 兵种与阵营名称优先采用游戏内官方简体中文译名；Mod 自创标签属于本汉化译法。
  新增用语请先看 EnemyIntelligenceFont.log 的缺字清单，避免再次出现问号。

兼容性与验证
- 启动时校验游戏文件哈希，游戏更新后需要等待兼容版本。
- 汉化改变了运行时载荷，因此本包标记为本地测试构建，尚未做游戏内实机验证。
- 离线测试覆盖解析、面板、安装、任务、重型敌人、呈现、分行与打包流程。

诊断
- 日志目录：%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs
- EnemyIntelligence.log：每次写入都会截断，只有最后一次内容，即最近的状态或绘制意图。
  排查时最后一行通常是
  drawing <界面> <任务> marquee=<字节数>B localized|ascii font=<字体哈希>
  如果停在 panel measuring / panel drawing（分行版为 rows fitting / rows drawing），
  说明卡在对应渲染阶段；其中 font= 可用于比对不同语言使用的字体是否一致。
- EnemyIntelligenceFont.log：字形覆盖报告。该文件给出当前字体/图集画不出来的字符，
  格式为 font missing <个数> <字符> font=<字体哈希>。缺失字符会被引擎画成问号，
  因此这份列表就是"文字显示为问号"的完整清单，无需逐个进游戏试。
  判定方式：私用区码位（U+E000 起）一定没有字形，其墨迹宽度即为缺字标记的宽度；
  凡与它宽度相同的字符，即由引擎替换成缺字标记。

卸载与恢复
- 关闭游戏，禁用本包，执行 Purge / Deploy。
- 需要英文原版时，改用上游的英文滚动版或 Rows 版安装包。
